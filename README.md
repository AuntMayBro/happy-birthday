# 🎂 Happy Birthday Too You

**"Bs Happy Birthday Bolna Tha"**

A fun and heartfelt way to wish someone a Happy Birthday via a beautifully designed webpage. This lightweight project makes it easy to share a custom online birthday surprise.

---

## 🌟 Features

- 🎉 Simple birthday greeting page
- 🎁 Surprise gift section
- 💖 Light, fast, and responsive
- 🎨 Custom-designed with CSS and animations

---

## 🚀 Live Demo

👉 [Click to view]((https://happy-birthday-too-you.vercel.app/))

---

## 📁 Project Structure

```
happy-birthday-too-you/
├── index.html         # Landing page with birthday message
├── gift.html          # Gift reveal page
├── style.css          # Styling for index.html
├── gift.css           # Styling for gift.html
├── script.js          # Script for index interactions
├── gift.js            # Script for gift page interactions
└── media/             # Images, audio, and other media
```

---

## 🛠️ Tech Stack

- **HTML5**
- **CSS3**
- **JavaScript (Vanilla)**

## 💻 How to Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/AuntMayBro/happy-birthday-too-you.git
   ```

2. Open the project folder:
   ```bash
   cd happy-birthday-too-you
   ```

3. Open `index.html` in your browser:
   - Or use Live Server extension in VS Code
